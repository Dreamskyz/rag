# RAG 项目示例文档

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种把「外部知识检索」
与「大语言模型生成」结合起来的技术。

典型流程：

1. 把本地文档切分成若干文本块
2. 用嵌入模型把文本块变成向量，存入向量数据库
3. 用户提问时，先检索最相关的文本块
4. 把检索结果作为上下文，交给大模型生成最终答案

## 本项目技术栈

- **LangChain**：编排文档加载、切分、检索与提示词链路
- **ChromaDB**：本地向量数据库，持久化到 `chroma_db/`
- **all-MiniLM-L6-v2**：轻量级英文/多语嵌入模型，用于文本向量化
- **Google Gemini（gemini-2.5-flash）**：负责根据检索上下文生成回答

## 支持的文档格式

请将文件放入 `docs/` 目录，当前支持：

- `.txt` 纯文本
- `.pdf` PDF 文档
- `.md` Markdown 文档

## 使用提示

把你自己的资料放进 `docs/` 后重新运行 `python main.py`，即可基于新文档提问。
